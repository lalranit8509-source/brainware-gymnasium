# Brainware University Gymnasium

A single-page student portal for the Brainware University Gymnasium — built for a B.Tech CSE (AIML) final-year project demonstration.

## Features
- Student registration (semester-wise, Google Form embed)
- Gym timings (Boys 4–8 PM, Girls 8–10 AM)
- AI Full Body Fitness Scanner (demo/estimate based)
- Diet charts (weight gain, weight management, muscle building, general fitness)
- Weekly exercise plans (beginner / intermediate / advanced)
- Trainer profile, facilities, student transformations
- BMI calculator
- Fitness dashboard with Chart.js progress charts
- Attendance with QR demo, notice board, help centre & FAQ

No membership, pricing, or payment features — free for all enrolled students.

## Tech stack
HTML5, CSS3, JavaScript, Chart.js, self-contained single file (no build step needed).

## Run locally
Just open `index.html` in any modern browser — no server or install required.
