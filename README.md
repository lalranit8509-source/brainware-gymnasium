# Brainware University Gymnasium

A single-page student portal for the Brainware University Gymnasium, created as a final-year B.Tech CSE (AIML) project demonstration. The app presents a complete gym experience for students, including registration, timings, fitness tracking, workout plans, attendance, notices, and support information in one interactive dashboard.

## Overview

This project is designed as a lightweight, static web application for a university gymnasium. It helps students:

- register for gym access
- check gym timings and schedules
- view fitness requirements and support information
- try a demo AI-based fitness scanner
- follow exercise and diet plans
- monitor BMI and progress
- access notice board and help center

## Features

- Student registration form with semester-wise roll listing
- Separate gym timing windows for boys and girls
- AI fitness scanner demo with estimated body metrics
- BMI calculator
- Weekly exercise plans by goal and skill level
- Diet chart for different fitness needs
- Trainer profile and facilities section
- Student transformation showcase
- Fitness dashboard with progress charts
- Attendance tracking with QR-style demo
- Notice board and FAQ/help center

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Chart.js
- Static single-file architecture (no build step required)

## Project Structure

- `index.html` — main project file containing the full app UI, styling, and JavaScript logic
- `README.md` — project documentation

## Run Locally

Because this is a static website, you can run it without installing dependencies:

1. Download or clone the repository.
2. Open `index.html` in any modern browser.
3. Alternatively, you can run a simple local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
